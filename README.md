# Torilo IQ Homepage - Handoff Note

## What's Built

- Completed the homepage based on the provided design.
- Implemented responsive layouts for desktop, tablet, and mobile.
- Added functional navigation and CTA buttons, except that it is not linked to any backend.
- Added interactive elements from the design.
- Added WhatsApp contact widget.
- Added back-to-top button.
- Tested the homepage across Chrome, Edge, and a mobile device.

## Known Limitations

- No major known limitations.
- Some third-party services/widgets depend on their external services being available.

## Design Decisions

- Where the design specification did not provide exact responsive behavior, the layout was adapted to maintain usability across different screen sizes.
- Kept the project structure light by consolidating main logic in `app.js` and storing media assets inside the `images/` directory.
